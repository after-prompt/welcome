- **Transformación**: el alpha de mañana, experimentado hoy
- **Sinergia**: mentes complementarias en un mismo lugar
- **Experimentación colectiva**: probamos, rompemos y aprendemos juntos

Sin agenda inflada. Sin slides de 40 minutos. Solo energía, interacción e improvisación.
